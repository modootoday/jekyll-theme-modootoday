# 가이드

처음 세 가이드부터 읽으세요. 설치, 설정, 마이그레이션과 업그레이드로 사이트가 테마 위에서 돌아갑니다. 그다음 주제별 가이드는 한 주제씩 다루므로 필요한 순서대로 읽으면 됩니다.

<!-- spec:docs-index:begin -->
- [설치](install/) — 기본 GitHub Pages 사이트나 Jekyll 4 사이트에 테마를 추가하고, 시작 사이트 템플릿에서 출발하며, 테마의 검사기로 빌드 결과를 확인합니다.
- [설정](configuration/) — _config.yml의 modootoday 키 아래에 두는 사이트 전체 설정을 모두 정리하고, 각 설정의 기본값, 바뀌는 점, 자세히 설명하는 페이지를 알려 줍니다.
- [마이그레이션과 업그레이드](upgrade/) — 다른 Jekyll 테마에서 사이트를 옮기는 방법, 기존 프로젝트에 테마를 도입하는 방법, 버전 사이에서 업그레이드할 때 바꿀 점을 단계별로 설명합니다.
- [첫 페이지](first-page/) — github.com과 사이트에서 똑같이 읽히는 페이지를 front matter, 섹션, 알림으로 써 보고, 그 페이지가 따르는 몇 가지 Markdown 규칙을 익힙니다.
- [커스터마이즈](customize/) — 토큰과 토큰 브리지로 색, 모서리, 글꼴을 바꾸고, 직접 만든 스타일시트를 더하거나 Sass 파셜을 덮어써서 테마를 사이트에 맞추는 방법을 설명합니다.
- [AI 에이전트](agents/) — 페이지마다 Markdown 버전, URL 별칭, llms.txt, llms-full.txt를 게시해 AI 에이전트가 사이트를 쓴 그대로 읽게 합니다.
- [접근성](accessibility/) — 키보드 사용, 스크린 리더, 휴대폰의 안전 영역, 터치 대상 크기, 고대비 모드, 동작 줄이기 설정을 테마가 어떻게 지원하는지 설명합니다.
- [성능](performance/) — 페이지마다 불러오는 파일, CDN에 오래 캐시해 두기 위한 버전 붙은 자산 URL, CI가 지키는 크기 예산을 설명하고 사이트를 가볍게 유지하는 방법을 알려 줍니다.
- [구조화 데이터](structured-data/) — 테마가 모든 페이지에 넣는 schema.org JSON-LD 그래프가 무엇을 담는지, 그리고 발행자, 작성자, 페이지 종류 같은 값을 설정하는 방법을 설명합니다.
- [번역 규칙](translation/) — 한국어와 일본어 문서, 인터페이스 문구를 번역할 때 지키는 정본 스타일 규칙, 문체, 용어집, 그리고 그 규칙을 검사하는 도구를 정리합니다.
