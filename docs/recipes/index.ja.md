# レシピ

各レシピはガイドを前提に、一つの作業を解決します。

<!-- spec:docs-index:begin -->
- [図とウィジェット](figures/) — ダイアグラム、数式、グラフをスクリプトなしでも表示される図にし、独自のインタラクティブな要素を配置します。
- [ブランドトークン](brand-tokens/) — トークンブリッジでブランドの色とフォントをテーマに反映し、サイトのスタイルシートと先読みするフォントまで厳格な CSP で使います。
- [CSP](csp/) — unsafe-inline なしの厳格な CSP でテーマを動かします。
- [検索](search/) — ヘッダー検索を有効にし、インデックスの内容と検索語の照合方法を決め、長いリストや表を読者が絞り込めるようにします。
- [生成ページ](generated-pages/) — JSON や YAML のデータファイルにあるレコードごとに、クラシックな GitHub Pages でページを 1 つずつ作り、全体を絞り込めるリストにまとめ、ファイルをバイト単位でそのまま公開します。
- [サイトの種類](site-types/) — 製品、会社、ドキュメント、個人、コミュニティのサイトをどのレイアウトで作るか、そしてどのサイトにも必要なシステムページをまとめます。
