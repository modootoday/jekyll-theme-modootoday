# レシピ

各レシピはガイドを前提に、一つの作業を解決します。

<!-- spec:docs-index:begin -->
- [図とウィジェット](figures/) — ダイアグラム、数式、グラフをスクリプトなしでも表示される図にし、独自のインタラクティブな要素を代わりのテキストと一緒に配置するレシピをまとめました。
- [ブランドトークン](brand-tokens/) — トークンブリッジでブランドの色とフォントをテーマに反映し、サイトのスタイルシートと先読みするフォントまで、厳格な CSP の下で一緒に使う方法を説明します。
- [CSP](csp/) — unsafe-inline なしの厳格な Content Security Policy でテーマを動かす方法です。送るヘッダーと、すべてのページを正しく動かす設定を説明します。
- [検索](search/) — ヘッダーの検索を有効にし、インデックスに入れる内容と検索語の照合方法を決め、長いリストや表を読者が入力して絞り込めるようにする方法を説明します。
- [生成ページ](generated-pages/) — JSON や YAML のデータファイルにあるレコードごとに、クラシックな GitHub Pages でページを 1 つずつ作り、全体を絞り込めるリストにまとめ、ファイルをバイト単位でそのまま公開します。
- [サイトの種類](site-types/) — 製品、会社、ドキュメント、個人、コミュニティのサイトをどのレイアウトで作るか、そしてどのサイトにも必要なシステムページを 1 ページにまとめます。
