# System pages

Add `404.md` with `layout: error`, use `redirect` for pages that moved, and give search its own page with `layout: search`. These pages use the small pages bundle; set `sitemap: false` on error pages so they stay out of the sitemap.

Layouts: `error`, `redirect`, `search`.
