# 레시피

각 레시피는 가이드를 바탕으로 작업 하나를 해결합니다.

<!-- spec:docs-index:begin -->
- [그림과 위젯](figures/) — 다이어그램, 수식, 차트를 스크립트 없이도 보이는 그림으로 만들고, 직접 만든 대화형 요소를 텍스트 대체 내용과 함께 넣는 레시피를 모았습니다.
- [브랜드 토큰](brand-tokens/) — 토큰 브리지로 브랜드의 색과 글꼴을 테마에 입히고, 사이트 스타일시트와 미리 불러오는 글꼴까지 엄격한 CSP 아래에서 함께 쓰는 방법을 설명합니다.
- [CSP](csp/) — unsafe-inline 없이 엄격한 콘텐츠 보안 정책에서 테마를 쓰는 방법입니다. 보낼 헤더와 모든 페이지가 제대로 동작하게 하는 설정을 설명합니다.
- [검색](search/) — 헤더 검색을 켜고, 색인에 담을 내용과 검색어를 맞추는 방식을 정하며, 독자가 긴 목록이나 표를 입력해서 거를 수 있게 하는 방법을 설명합니다.
- [생성 페이지](generated-pages/) — JSON이나 YAML 데이터 파일의 레코드마다 클래식 GitHub Pages에서 페이지를 하나씩 주고, 전체를 거를 수 있는 목록을 만들고, 파일을 바이트 그대로 게시합니다.
- [설치할 수 있는 사이트](pwa/) — 이미 있는 사이트 설정으로 웹 앱 매니페스트를 만들어 브라우저가 사이트를 앱처럼 설치할 수 있게 하는 방법과 아이콘, 설치 가능 여부를 확인하는 방법을 설명합니다.
- [사이트 유형](site-types/) — 제품, 회사, 문서, 개인, 커뮤니티 사이트를 어떤 레이아웃으로 만드는지, 그리고 모든 사이트에 필요한 시스템 페이지를 정리합니다.
