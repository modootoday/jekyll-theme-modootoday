# 레시피

각 레시피는 가이드를 바탕으로 작업 하나를 해결합니다.

<!-- spec:docs-index:begin -->
- [그림과 위젯](figures/) — 다이어그램, 수식, 차트를 스크립트 없이도 보이는 그림으로 만들고, 직접 만든 대화형 요소를 넣습니다.
- [브랜드 토큰](brand-tokens/) — 토큰 브리지로 브랜드의 색과 글꼴을 테마에 입히고, 사이트 스타일시트와 미리 불러오는 글꼴까지 엄격한 CSP에서 씁니다.
- [CSP](csp/) — unsafe-inline 없이 엄격한 CSP에서 테마 쓰기.
- [검색](search/) — 헤더 검색을 켜고, 색인에 담을 내용과 검색어를 맞추는 방식을 정하고, 긴 목록이나 표를 독자가 거를 수 있게 합니다.
- [생성 페이지](generated-pages/) — JSON이나 YAML 데이터 파일의 레코드마다 클래식 GitHub Pages에서 페이지를 하나씩 주고, 전체를 거를 수 있는 목록을 만들고, 파일을 바이트 그대로 게시합니다.
- [사이트 유형](site-types/) — 제품, 회사, 문서, 개인, 커뮤니티 사이트를 어떤 레이아웃으로 만드는지, 그리고 모든 사이트에 필요한 시스템 페이지를 정리합니다.
<!-- spec:docs-index:end -->
