# 그림과 위젯

이 레시피들은 GitHub가 이미 이해하는 Markdown(Mermaid나 수식 펜스, 표)을 사이트의 그림으로 바꾸고, 텍스트 대체 내용이 있는 사용자 정의 요소를 넣습니다. 모두 엄격한 CSP에서 동작합니다.

<!-- spec:docs-index:begin -->
- [수식과 다이어그램](math-diagrams/) — Mermaid 다이어그램과 수식을 커밋한 정적 SVG와 MathML로 보여 주거나, 내장 로더나 직접 만든 로더로 다이어그램과 KaTeX 수식을 렌더링하는 방법과 각 방법이 CSP와 개인정보에 미치는 영향.
- [다이어그램과 수식 로더](loaders/) — 내장 로더나 직접 만든 로더로 Mermaid 다이어그램과 KaTeX 수식을 브라우저에서 렌더링하는 방법과 각 방법이 CSP와 개인정보에 요구하는 것을 설명합니다.
- [차트](charts/) — Markdown 표를 차트 figure로 바꾸거나 데이터 파일을 차트로 보여 주고, 표는 모든 독자가 받는 텍스트로 남깁니다.
- [위젯](widgets/) — 직접 만든 custom element를 Markdown에서 페이지에 넣고, JavaScript가 없는 독자에게는 대신 읽을 텍스트를 줍니다.
