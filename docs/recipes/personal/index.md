# Personal site

Put a `links` page at `/`, a `resume` at `/cv/` and `portfolio` with `project` pages for your work. Use the same `name` on the link page and the resume so both ProfilePages describe one Person; print the resume from the browser to get a clean PDF.

Layouts: `links`, `resume`, `portfolio`.
