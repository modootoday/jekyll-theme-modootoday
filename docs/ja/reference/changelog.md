# 変更履歴

完全な履歴は [CHANGELOG.md](https://github.com/modootoday/jekyll-theme-modootoday/blob/main/CHANGELOG.md) にあります。

> [!NOTE]
> このページは[英語の原文](../../../reference/changelog/)の翻訳です。内容が異なる場合は英語版が優先されます。

## 1.0.0 (最初のリリース)

RubyGems で最初に公開されるバージョンです。

- コンポーネント: アラート、セクション、カード、ボタン、タブ、バッジ、表、アコーディオン、ステップ、図、タイムライン、キーボードのキー、パンくずリスト、目次、テーマ切り替え、クライアント検索、`post` レイアウト。
- デザイントークン (`--mt-*`)、コンポーネントごとの Sass パーシャル、`modootoday:` 設定ブロック。
- 確定したコンテンツルール (`md-components v1`)、安定した[公開 API](../api/)、`modootoday-check` チェッカー。
- 既定の SEO タグ、言語切り替え、右から左の文字のサポート、厳格な CSP のサポート、スロット契約。
- AI エージェント向けの Markdown ツインと `llms.txt`。
- 英語、韓国語、日本語のドキュメント。

1.0.0 より前にリポジトリから直接ビルドしたサイトは[移行とアップグレード](../../guides/upgrade/)をお読みください。

> [!IMPORTANT]
> ルールは `md-components v1` として確定しました。変更は `CHANGELOG.md` に記録されます。
