# 個人サイト

`/` に `links` ページ、`/cv/` に `resume`、作品は `portfolio` と `project` ページに置きます。リンクページと履歴書で同じ `name` を使えば、2 つの ProfilePage が 1 人の Person を表します。履歴書はブラウザーから印刷するときれいな PDF になります。

レイアウト: `links`, `resume`, `portfolio`.
