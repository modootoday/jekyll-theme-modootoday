# コミュニティサイト

集まりは `events` とイベントごとの `event` ページで並べ、計画は `now`、`next`、`later` に分けた `roadmap` で共有し、支援者には `sponsors` で感謝を伝えます。ロードマップの項目を Issue にリンクすると、読者が進み具合を追えます。

レイアウト: `events`, `event`, `roadmap`, `sponsors`.
