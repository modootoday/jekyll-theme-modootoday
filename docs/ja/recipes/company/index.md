# 会社のページ

人は `team`、採用は `jobs` と募集ごとの `job` ページ、連絡方法は `contact`、規約とプライバシーは `effective` の日付を付けた `legal` で作ります。サイトの `publisher` を 1 度設定すれば、すべてのページの構造化データが同じ Organization を指します。

レイアウト: `team`, `jobs`, `contact`, `legal`.
