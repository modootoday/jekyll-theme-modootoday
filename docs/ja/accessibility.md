# アクセシビリティ

> [!NOTE]
> このページは[英語の原文](../../accessibility/)の翻訳です。内容が異なる場合は英語版が優先されます。

テーマは設定なしで WCAG 2.2 AA を目指しています。このページでは、テーマが読者のために行うことと、それを変える 2 つの設定をまとめます。

## キーボード

| キー | 場所 | 動作 |
|---|---|---|
| `Tab` | すべてのページ | 最初の移動先は「本文へスキップ」で、本文にフォーカスを移します |
| `/` または `Ctrl`+`K` (macOS では `Cmd`+`K`) | 検索のあるページ | 検索ボックスにフォーカス (入力欄で入力中の `/` は無視) |
| `↓` `↑` | 検索結果 | 結果の間を移動し、検索ボックスに戻る |
| `Esc` | 検索 | 結果から抜ける、または検索ボックスを空にする |
| `←` `→` `Home` `End` | タブ | タブを切り替え。右から左に書くページでは左右が読む方向に従います |
| `↓` `↑` `Esc` | 言語メニュー、ナビの「その他」メニュー、ページ操作 | 項目間を移動。`Esc` で閉じてフォーカスを戻します |
| `Tab` | 幅の広いコードブロックと表 | 横にスクロールするブロックは名前付きの領域になり、フォーカスして矢印キーでスクロールできます |

フォーカスは常に見えます。タブ、パネル、スクロール領域の中では、フォーカスリングが切れないよう枠の内側に描かれます。

## スクリーンリーダー

ランドマーク (ヘッダー、ナビゲーション、本文、フッター)、ナビゲーション・パンくず・言語メニューの現在ページ (`aria-current`)、アイコンボタン・コードブロック・表のラベルが組み込まれています。ラベルは `lang:` に従って 23 言語で表示されます ([設定](../configuration/#言語)を参照)。ラベルのないアイコンは装飾として扱われます。

## スマートフォンとタブレット

- **セーフエリア。** ページはノッチ、角丸、ホームインジケーターの下まで描かれ、ヘッダー・左右の余白・フッターはそれらを避けて配置されます。
- **タッチターゲット。** タッチ画面では、ヘッダーのリンク、メニュー、タブ、コピーボタン、ページ送りの高さが 44 px 以上になり、検索ボックスの文字は 16 px なので iOS で拡大されません。
- **ブラウザの色。** アドレスバーの色がライト・ダークモードのページ背景に合わせられます。

## ハイコントラストと動き

- Windows のハイコントラスト (強制カラー) でも、アイコンボタンと検索ボックスの枠線が表示されます。
- 「視差効果を減らす」をオンにすると、トランジションとアニメーションが止まります。

## 設定

```yaml
modootoday:
  viewport_fit: auto           # default: cover (draw under the notch with safe-area padding)
  theme_color: {light: "#ffffff", dark: "#0d1117"}  # or one "#hex", or false
```

| キー | 既定値 | 効果 |
|---|---|---|
| `viewport_fit` | `cover` | `auto` はページをセーフエリア内に収め、余白をブラウザに任せます |
| `theme_color` | ページ背景 | ブラウザのバーの色。`"#hex"` 1 つ、`{light, dark}`、またはタグを出さない `false` |

独自の CSS では、`--mt-safe-top`、`--mt-safe-right`、`--mt-safe-bottom`、`--mt-safe-left` で余白の値を読めます。

## コンテンツ

コンテンツそのものはテーマでは直せません。リンクの文言と画像の `alt` テキストは内容がわかるように書き、各ページの `#` 見出しは 1 つにして、見出しのレベルを飛ばさないでください。
