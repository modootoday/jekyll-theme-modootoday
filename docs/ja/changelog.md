# 変更履歴

完全な履歴は [CHANGELOG.md](https://github.com/modootoday/jekyll-theme-modootoday/blob/main/CHANGELOG.md) にあります。

> [!NOTE]
> このページは[英語の原文](../../changelog/)の翻訳です。内容が異なる場合は英語版が優先されます。

## 0.5.0 (最初のリリース、未公開)

最初の公開バージョンです。以下の内部マイルストーンをまとめたもので、これらは RubyGems に公開されたことはありません。

### マイルストーン 0.5

- このドキュメントサイト、キッチンシンク、QA ジョブ (スクリーンショット、axe、コントラスト、サイズ予算)。 `status:available`

### マイルストーン 0.4

- タイムライン、キーボードのキー、クライアント検索、`post` レイアウト。 `since:0.4`
- CI で生成する読み取り専用の DTCG `tokens.json`。

### マイルストーン 0.3

- テーマ切り替え、パンくずリスト、目次、アコーディオン、ステップ、図、タグと導入バージョンのバッジ。 `since:0.3`

### マイルストーン 0.2

- デザイントークン、コンポーネントごとの Sass パーシャル、`modootoday:` 設定ブロック。 `since:0.2`
- ナビゲーション、前後のページへのリンク、コードのコピーボタン。

### マイルストーン 0.1

- 最初のバージョン: アラート、セクション、カード、ボタン、タブ、ステータスバッジ、ツイン、チェッカー。

> [!IMPORTANT]
> ルールは `md-components v1` として確定しています。1.0 以降、ルールの削除や厳格化はメジャーバージョンでのみ行います。
