# ワイド

このページは `layout: wide` を使います。ヘッダーとフッターはそのままで、カードグリッド、表、ギャラリーのためにコンテナ幅いっぱいを使います。

| レイアウト | ヘッダー | 幅 |
|---|---|---|
| minimal | なし | 狭い |
| wide | あり | コンテナ |
| home | あり | コンテナ |
