# レイアウト

フロントマターの `layout:` でレイアウトを指定します。指定のないページは `doc` を使います。

| レイアウト | 用途 |
| --- | --- |
| `doc` | 目次、パンくず、サイドバー付きのドキュメントページ |
| `post` | `_posts/` のブログ記事 |
| `archive` | タグとカテゴリーの一覧ページ |
| `default` | ヘッダー、本文、フッターだけのページ |

<!-- spec:docs-index:begin -->
- [ブログとニュース](blog-news/) — ブログ一覧、ニュースのトップページ、署名、著者ページ、Atom フィードを作ります。
