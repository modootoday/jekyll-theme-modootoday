# レイアウト

フロントマターの `layout:` でレイアウトを指定します。指定のないページは `doc` を使います。

| レイアウト | 用途 |
| --- | --- |
| `doc` | 目次、パンくず、サイドバー付きのドキュメントページ |
| `post` | `_posts/` のブログ記事 |
| `archive` | タグとカテゴリーの一覧ページ |
| `default` | ヘッダー、本文、フッターだけのページ |

<!-- spec:docs-index:begin -->
- [ページシェル](shells/) — ページの種類ごとのシェルと、レイアウト単位で読み込む任意のスタイルシートです。
- [ディレクトリレイアウト](directory/) — プロジェクト、メンバー、求人、イベント、スポンサー、連携をカード一覧で表示し、JavaScript なしで絞り込めます。
- [詳細ページ](detail/) — プロジェクト、事例、求人、イベント、ポッドキャストのエピソードを1件ずつ表示し、概要リスト、行動喚起1つ、構造化データを備えます。
- [ブログとニュース](blog-news/) — ブログ一覧、ニュースのトップページ、署名、著者ページ、Atom フィードを作ります。
