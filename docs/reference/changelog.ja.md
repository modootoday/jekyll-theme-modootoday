# 変更履歴

すべてのリリースを新しい順に、変更ごとの書き出しとともに示す一覧は、[英語の変更履歴ページ](../../../reference/changelog/)にあります。リリースの記録は CHANGELOG.md から英語で作られるため、このページには載せません。理由や根拠となる決定まで含む完全な記録は [CHANGELOG.md](https://github.com/modootoday/jekyll-theme-modootoday/blob/main/CHANGELOG.md) にあり、各バージョンは GitHub のリリースにリンクしています。サイトを新しいリリースに移すには[移行とアップグレード](../../guides/upgrade/)をお読みください。フィードリーダーでは、[リリース一覧の Atom フィード](../../../changelog.xml)(リリースごとに一つの項目)か [GitHub のリリースのフィード](https://github.com/modootoday/jekyll-theme-modootoday/releases.atom)を購読できます。
