# 레퍼런스

안정된 이름, 명령 옵션, 릴리스, 계획한 작업을 여기서 찾아보세요.

<!-- spec:docs-index:begin -->
- [공개 API](api/) — 이 테마가 사이트용으로 문서화한 이름, 클래스, include, 파일을 정리합니다. 이들은 메이저 버전 안에서 그대로 유지되며, 바뀌는 방식도 설명합니다.
- [Markdown 규칙](rules/) — 모든 페이지 본문이 따르는 md-components v1 규칙입니다. github.com, 테마, Markdown 버전에서 똑같이 보이게 하는 기준을 정리합니다.
- [명령줄](cli/) — 검사기 modootoday-check와 스텁 작성기 modootoday-stubs의 모든 옵션, 그리고 각 종료 코드의 뜻을 정리합니다.
- [스타터 데모 쇼케이스](showcase/) — 스타터의 라이브 데모에 테마 이름과 문서 링크를 담은 막대나 알약을 보여 주고, 복사한 사이트에는 나오지 않게 하는 방법을 설명합니다.
- [변경 기록](changelog/) — 테마의 모든 릴리스를 최신순으로 보여 줍니다. 변경마다 한 줄 요약을 붙이고, 이유와 결정까지 담은 전체 기록으로 가는 링크를 함께 둡니다.
- [로드맵](roadmap/) — 테마가 지금 지원하는 것, 동작하는 환경과 버전, 다음에 계획한 작업의 주제를 정리합니다. 작업 진행은 저장소의 이슈에서 따라갈 수 있습니다.
