# リファレンス

安定した名前、コマンドのオプション、リリース、計画している作業をここで調べてください。

<!-- spec:docs-index:begin -->
- [公開 API](api/) — このテーマがサイト向けに文書化している名前、クラス、ファイル。
- [Markdown ルール](rules/) — すべてのページ本文が従う md-components v1 のルールです。github.com、テーマ、Markdown 版で同じように表示するための基準をまとめます。
- [コマンドライン](cli/) — チェッカー modootoday-check とスタブ作成の modootoday-stubs のすべてのオプションと、各終了コードの意味をまとめます。
- [スターターのデモのショーケース](showcase/) — スターターのライブデモにテーマ名とドキュメントへのリンクを載せたバーかピルを表示し、コピーしたサイトには出さない方法を説明します。
- [変更履歴](changelog/) — テーマのすべてのリリースを新しい順に、変更ごとの 1 行の要約と完全な記録へのリンクを添えて示します。
- [ロードマップ](roadmap/) — テーマがいまサポートしている機能、動作する環境、次に計画している作業のテーマをまとめます。
