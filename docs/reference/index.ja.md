# リファレンス

<!-- spec:docs-index:begin -->
- [公開 API](api/) — このテーマがサイト向けに文書化している名前、クラス、ファイル。
- [タグ](../../ja/tags/) — このサイトのすべての記事をタグ別にまとめています。
- [カテゴリー](../../ja/categories/) — このサイトのすべての記事をカテゴリー別にまとめています。
- [変更履歴](changelog/) — テーマのすべてのリリースを新しい順に、変更ごとの 1 行の要約と完全な記録へのリンクを添えて示します。
- [ロードマップ](roadmap/) — テーマがいまサポートしている機能、動作する環境、次に計画している作業のテーマをまとめます。
