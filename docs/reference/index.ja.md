# リファレンス

安定した名前、コマンドのオプション、リリース、計画している作業をここで調べてください。

<!-- spec:docs-index:begin -->
- [公開 API](api/) — このテーマがサイト向けに文書化している名前、クラス、include、ファイルをまとめます。メジャーバージョンの中では変わらず、変わるときの決まりも説明します。
- [Markdown ルール](rules/) — すべてのページ本文が従う md-components v1 のルールです。github.com、テーマ、Markdown 版で同じように表示するための基準をまとめます。
- [コマンドライン](cli/) — チェッカー modootoday-check とスタブ作成の modootoday-stubs のすべてのオプションと、各終了コードの意味をまとめます。
- [スターターのデモのショーケース](showcase/) — スターターのライブデモに、テーマ名とドキュメントへのリンクを載せたバーかピルを表示し、そこからコピーしたサイトには出さない方法を説明します。
- [変更履歴](changelog/) — テーマのすべてのリリースを新しい順に並べた英語の変更履歴ページと、理由や決定まで書いた完全な記録、リリースを購読できる Atom フィードへの道筋を案内します。
- [ロードマップ](roadmap/) — テーマがいまサポートしている機能、動作する環境とバージョン、次に計画している作業のテーマをまとめます。進み具合はリポジトリの Issue で追えます。
