# 변경 기록

모든 릴리스를 최신순으로, 변경마다 첫 구절과 함께 보여 주는 목록은 [영어 변경 기록 페이지](../../../reference/changelog/)에 있습니다. 릴리스 기록은 CHANGELOG.md에서 영어로 만들어지므로 이 페이지에 옮겨 싣지 않습니다. 이유와 근거 결정까지 담긴 전체 기록은 [CHANGELOG.md](https://github.com/modootoday/jekyll-theme-modootoday/blob/main/CHANGELOG.md)에 있고, 각 버전은 GitHub 릴리스로 연결됩니다. 사이트를 새 릴리스로 옮기려면 [마이그레이션과 업그레이드](../../guides/upgrade/)를 읽으세요. 피드 리더로는 [릴리스 목록의 Atom 피드](../../../changelog.xml)(릴리스마다 항목 하나)나 [GitHub 릴리스 피드](https://github.com/modootoday/jekyll-theme-modootoday/releases.atom)를 구독할 수 있습니다.
