# 投稿のデモ

ライブデモはブログ用スターターの投稿です。`_posts` のファイルは既定で `layout: post` を使います。本文の上にタイトル、リード文、著者、日付、読了時間、カバーを、下にシリーズ、タグとカテゴリー、共有リンク、前後の投稿、関連する投稿を表示し、`BlogPosting` の構造化データを出力します。

投稿のレイアウトの front matter と著者のデータ、フィードは[ブログとニュース](../)にあります。
