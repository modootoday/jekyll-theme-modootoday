# 글 데모

라이브 데모는 블로그 시작 사이트의 글 한 편입니다. `_posts`의 파일은 기본으로 `layout: post`를 씁니다. 본문 위에는 제목, 부제, 작성자, 날짜, 읽는 시간, 표지를, 아래에는 시리즈, 태그와 카테고리, 공유 링크, 이전 글과 다음 글, 관련 글을 보여 주고 `BlogPosting` 구조화 데이터를 출력합니다.

글 레이아웃의 front matter와 작성자 데이터, 피드는 [블로그와 뉴스](../)에 있습니다.
