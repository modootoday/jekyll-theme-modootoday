# Blog demo

The live demo is the home page of the blog starter, a `layout: blog` page that prints its text and then the site's posts as cards in a `list`, a `grid` or a `magazine` whose first post leads, with newer and older links from `jekyll-paginate`. This site's own [blog](../../../blog/) uses the layout too.

[Blog and news](../) lists the front matter of the blog layout and the settings it reads.
