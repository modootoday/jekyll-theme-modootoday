# ブログのデモ

ライブデモはブログ用スターターのトップページです。`layout: blog` のページは本文の後にサイトの投稿をカードで並べ、シンプルな `list`、`grid`、最初の投稿を大きく見せる `magazine` から選べ、`jekyll-paginate` で新しい投稿と古い投稿へのリンクを付けます。このサイトの[ブログ](../../blog/index.ja.md)もこのレイアウトを使っています。

ブログのレイアウトの front matter と読み込む設定は[ブログとニュース](index.ja.md)にあります。
