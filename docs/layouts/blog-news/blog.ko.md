# 블로그 데모

라이브 데모는 블로그 시작 사이트의 첫 페이지입니다. `layout: blog` 페이지는 본문 다음에 사이트의 글을 카드로 보여 주며, 평범한 `list`, `grid`, 첫 글을 크게 보여 주는 `magazine` 중에서 고르고 `jekyll-paginate`로 새 글과 이전 글 링크를 답니다. 이 사이트의 [블로그](../../../blog/)도 이 레이아웃을 씁니다.

블로그 레이아웃의 front matter와 읽는 설정은 [블로그와 뉴스](../)에 있습니다.
