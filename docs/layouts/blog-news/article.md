# Theme update improves keyboard access

**Seoul, 29 October.** A maintenance release of modootoday is rolling out today. It changes no settings, so most sites only need to rebuild.

## What is new

- The sidebar keeps focus visible while you move through long sections.
- Links that open a new window now say so to screen readers, in 23 languages.
- Sample links in demo pages no longer navigate away.

## What comes next

The team will publish the full audit in the coming weeks. This article will be updated as the release reaches more sites.
