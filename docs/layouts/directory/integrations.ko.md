# 연동 데모

라이브 데모는 레코드 다섯 개로 만든 문서 시작 사이트의 플러그인 목록입니다. `layout: integrations` 페이지의 카드마다 로고, 이름, 분류, 한 줄 설명이 있고 레코드 페이지로 연결되며, 버튼 한 줄이 JavaScript 없이 분류별로 카드를 거릅니다.

모든 디렉터리 레이아웃의 front matter는 [디렉터리 레이아웃](../)에, 레코드마다 페이지를 만드는 방법은 [생성 페이지](../../../recipes/generated-pages/)에 있습니다.
