# 連携のデモ

ライブデモは 5 件のレコードから作ったドキュメント用スターターのプラグイン一覧です。`layout: integrations` のページではカードごとにロゴ、名前、分類、1 行の説明があってレコードのページにリンクし、1 列のボタンが JavaScript なしで分類ごとにカードを絞り込みます。

すべてのディレクトリ系レイアウトの front matter は[ディレクトリレイアウト](../)に、レコードごとにページを作る方法は[生成ページ](../../../recipes/generated-pages/)にあります。
