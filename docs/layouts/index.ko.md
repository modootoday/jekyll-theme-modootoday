# 레이아웃

front matter의 `layout:`으로 레이아웃을 지정합니다. 지정하지 않은 페이지는 `doc`을 씁니다. 아래의 그룹 페이지마다 레이아웃의 front matter를 표 하나에 모으고 레이아웃별 데모로 연결합니다.

| 레이아웃 | 용도 |
| --- | --- |
| `doc` | 목차, 이동 경로, 사이드바가 있는 문서 페이지 |
| `post` | `_posts/`의 블로그 글 |
| `archive` | 태그와 카테고리 목록 페이지 |
| `default` | 헤더, 본문, 푸터만 있는 기본 페이지 |

<!-- spec:docs-index:begin -->
- [페이지 셸](shells/) — 홈, 오류, 리디렉션, 검색처럼 페이지 종류마다 쓰는 셸과, 각 레이아웃이 필요한 페이지에서만 따로 불러오는 선택 스타일시트를 설명합니다.
- [디렉터리 레이아웃](directory/) — 프로젝트, 구성원, 채용, 행사, 후원사, 연동을 카드 목록으로 보여 주고, JavaScript 없이 동작하는 필터로 독자가 원하는 카드만 골라 보게 합니다.
- [상세 페이지](detail/) — 프로젝트, 사례 연구, 채용 공고, 행사, 팟캐스트 에피소드를 한 페이지에 하나씩 보여 주며 정보 목록, 행동 유도 하나, 구조화 데이터를 갖춥니다.
- [마케팅 페이지](marketing/) — 기능, 요금, 다운로드, 브랜드, 링크, 문의 페이지를 공유 선택 스타일시트 하나로 만드는 레이아웃과 각 레이아웃의 front matter를 설명합니다.
- [블로그와 뉴스](blog-news/) — 블로그 목록, 뉴스 첫 화면, 글의 작성자 정보, 작성자 페이지, 언어별 Atom 피드를 만드는 레이아웃과 각 레이아웃의 front matter를 설명합니다.
- [문서 확장](docs-extra/) — 레퍼런스, 변경 이력, 로드맵, 용어집, 허브, 강좌, 책 페이지를 공유 선택 스타일시트 하나로 만드는 레이아웃과 각 레이아웃의 front matter를 설명합니다.
- [문서](documents/) — 날짜, 버전, 목차가 있는 법적 고지 페이지와 인쇄를 먼저 고려한 이력서, 사람들이 보관하거나 인쇄하는 페이지를 위한 레이아웃 두 가지입니다.
