# 와이드

이 페이지는 `layout: wide`를 씁니다. 헤더와 푸터는 그대로 두고, 카드 그리드·표·갤러리를 위해 컨테이너 폭 전체를 씁니다.

| 레이아웃 | 헤더 | 폭 |
|---|---|---|
| minimal | 없음 | 좁음 |
| wide | 있음 | 컨테이너 |
| home | 있음 | 컨테이너 |
