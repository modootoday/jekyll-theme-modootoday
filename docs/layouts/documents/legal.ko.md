# 약관 데모

라이브 데모는 랜딩 시작 사이트의 개인정보 처리방침입니다. `layout: legal` 페이지는 본문 위에 시행일, 마지막 수정일, 버전을 보여 주고, `##`와 `###` 제목으로 목차를 만들며, 인쇄할 때는 사이트 머리글, 바닥글, 배너를 숨깁니다.

약관 레이아웃과 이력서 레이아웃의 front matter는 [문서](../)에 있습니다.
