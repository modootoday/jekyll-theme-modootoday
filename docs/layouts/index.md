# Layouts

Set a layout with `layout:` in front matter. Pages without one use `doc`.

| Layout | Use it for |
| --- | --- |
| `doc` | Documentation pages with a table of contents, breadcrumb and sidebar |
| `post` | Blog posts in `_posts/` |
| `archive` | Tag and category index pages |
| `default` | A bare page: header, body and footer only |
