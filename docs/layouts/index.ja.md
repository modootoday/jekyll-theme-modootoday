# レイアウト

front matter の `layout:` でレイアウトを指定します。指定のないページは `doc` を使います。下のグループのページごとに、レイアウトの front matter を 1 つの表にまとめ、レイアウトごとのデモにリンクします。

| レイアウト | 用途 |
| --- | --- |
| `doc` | 目次、パンくず、サイドバー付きのドキュメントページ |
| `post` | `_posts/` のブログ記事 |
| `archive` | タグとカテゴリーの一覧ページ |
| `default` | ヘッダー、本文、フッターだけのページ |

<!-- spec:docs-index:begin -->
- [ページシェル](shells/) — ホーム、エラー、リダイレクト、検索など、ページの種類ごとのシェルと、各レイアウトが必要なページだけで読み込む任意のスタイルシートを説明します。
- [ディレクトリレイアウト](directory/) — プロジェクト、メンバー、求人、イベント、スポンサー、連携をカード一覧で表示し、JavaScript なしで動く絞り込みで読者が見たいカードだけを選べるようにします。
- [詳細ページ](detail/) — プロジェクト、事例、求人、イベント、ポッドキャストのエピソードを 1 件ずつ 1 ページで表示し、概要のリスト、行動喚起 1 つ、構造化データを備えます。
- [マーケティングページ](marketing/) — 機能、料金、ダウンロード、ブランド、リンク、お問い合わせのページを共通の任意スタイルシートで作るレイアウトと、それぞれの front matter を説明します。
- [ブログとニュース](blog-news/) — ブログ一覧、ニュースのトップページ、記事の署名、著者ページ、言語ごとの Atom フィードを作るレイアウトと、それぞれの front matter を説明します。
- [ドキュメント拡張](docs-extra/) — リファレンス、変更履歴、ロードマップ、用語集、ハブ、コース、書籍のページを共通の任意スタイルシート 1 つで作るレイアウトと、それぞれの front matter を説明します。
- [文書](documents/) — 日付、版、目次のある法的なページと、印刷を優先した履歴書です。人が保存したり印刷したりするページのために用意した 2 つのレイアウトを説明します。
