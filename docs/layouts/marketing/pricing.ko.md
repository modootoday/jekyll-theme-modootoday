# 요금제 데모

라이브 데모는 랜딩 시작 사이트의 요금 페이지입니다. `layout: pricing` 페이지는 요금제마다 카드를 하나씩 보여 주고, 라디오 버튼 두 개로 만든 월간/연간 전환이 CSS만으로 가격을 바꾸며, 추천 요금제는 텍스트로 표시합니다.

요금제 레이아웃과 다른 마케팅 레이아웃의 front matter는 [마케팅 페이지](../)에 있습니다.
