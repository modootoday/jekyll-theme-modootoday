# 料金のデモ

ライブデモはランディング用スターターの料金ページです。`layout: pricing` のページはプランごとにカードを 1 枚表示し、2 つのラジオボタンでできた月額/年額の切り替えが CSS だけで価格を変え、おすすめのプランはテキストで示します。

料金のレイアウトとほかのマーケティング系レイアウトの front matter は[マーケティングページ](../)にあります。
