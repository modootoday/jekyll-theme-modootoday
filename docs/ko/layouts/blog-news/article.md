# 테마 업데이트로 키보드 사용이 편해져요

**서울, 10월 29일.** 오늘부터 modootoday 유지보수 릴리스가 배포돼요. 설정은 바뀌지 않아서 대부분의 사이트는 다시 빌드만 하면 돼요.

## 바뀐 점

- 긴 사이드바를 이동할 때도 포커스가 계속 보여요.
- 새 창으로 열리는 링크를 화면 낭독기가 23개 언어로 알려 줘요.
- 데모 페이지의 예시 링크를 눌러도 다른 곳으로 이동하지 않아요.
