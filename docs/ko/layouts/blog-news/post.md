# 다크 모드에서도 버티는 색 고르기

처음 만든 다크 테마는 밝은 색을 그냥 뒤집은 것이었어요. 본문은 괜찮았지만 링크는 형광색이 되고, 테두리는 사라지고, 코드 블록은 번쩍였어요. 지금 쓰는 세 가지 원칙을 정리했어요.

## 색상보다 대비부터

글자 토큰은 배경과 4.5:1, 테두리는 3:1 대비를 확인해요. 밝기를 맞춘 다음에 색상을 골라요.

## 배경이 어두울수록 채도는 낮게

흰 바탕에서 차분하던 파랑도 검은 바탕에서는 떨려 보여요. 다크 팔레트는 같은 색상에 채도를 20%쯤 낮춰요.

## 실제 내용으로 확인하기

표, 콜아웃, 문법 강조 코드는 색 견본에서는 안 보이는 문제를 잡아내요. 바꾸기 전에 [키친 싱크](#)를 두 테마로 열어 보세요.

> 글보다 색이 먼저 눈에 들어오면 너무 강한 거예요.
