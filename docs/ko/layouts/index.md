# 레이아웃

프런트 매터의 `layout:`으로 레이아웃을 지정합니다. 지정하지 않은 페이지는 `doc`을 씁니다.

| 레이아웃 | 용도 |
| --- | --- |
| `doc` | 목차, 이동 경로, 사이드바가 있는 문서 페이지 |
| `post` | `_posts/`의 블로그 글 |
| `archive` | 태그와 카테고리 목록 페이지 |
| `default` | 헤더, 본문, 푸터만 있는 기본 페이지 |
