# 회사 페이지

사람은 `team`, 채용은 `jobs`와 공고마다 `job` 페이지 하나, 연락 방법은 `contact`, 약관과 개인정보 처리방침은 `effective` 날짜를 넣은 `legal`로 만드세요. 사이트 `publisher`를 한 번만 정하면 모든 페이지의 구조화 데이터가 같은 Organization을 가리킵니다.

레이아웃: `team`, `jobs`, `contact`, `legal`.
