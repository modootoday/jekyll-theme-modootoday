# 변경 기록

전체 기록은 [CHANGELOG.md](https://github.com/modootoday/jekyll-theme-modootoday/blob/main/CHANGELOG.md)에 있습니다.

> [!NOTE]
> 이 페이지는 [영어 원문](../../changelog/)의 번역입니다. 내용이 다르면 영어 문서가 우선합니다.

## 0.5.0 (첫 릴리스, 아직 미발행)

첫 공개 버전입니다. 아래 내부 마일스톤을 합친 것으로, 이전 버전은 RubyGems에 발행된 적이 없습니다.

### 마일스톤 0.5

- 이 문서 사이트, 키친싱크, QA 작업(스크린숏, axe, 대비, 용량 예산). `status:available`

### 마일스톤 0.4

- 타임라인, 키보드 키, 클라이언트 검색, `post` 레이아웃. `since:0.4`
- CI에서 만드는 읽기 전용 DTCG `tokens.json`.

### 마일스톤 0.3

- 테마 전환, 브레드크럼, 목차, 아코디언, 단계, 그림, tag·since 배지. `since:0.3`

### 마일스톤 0.2

- 디자인 토큰, 컴포넌트별 Sass 파셜, `modootoday:` 설정 블록. `since:0.2`
- 내비게이션, 이전/다음 링크, 코드 복사 버튼.

### 마일스톤 0.1

- 첫 버전: 알림, 섹션, 카드, 버튼, 탭, 상태 배지, 쌍둥이, 검사기.

> [!IMPORTANT]
> 규칙은 `md-components v1`로 확정되었습니다. 1.0부터 규칙의 제거나 강화는 메이저 버전에서만 합니다.
