# Example Docs

Plain Markdown pages, styled by the theme.

[Read the guide](guide/) [Source](https://github.com/modootoday/jekyll-theme-modootoday)

## Features

- **Alerts** — GitHub alert syntax becomes styled callouts. `status:available`
- **Tabs**: install snippets turn into tabs. `status:partial`
- **Style guide**: a dev-only component gallery. `status:planned`

## Install

### Ruby

```sh
gem install example-tool
```

### npm

```sh
npm install example-tool
```
