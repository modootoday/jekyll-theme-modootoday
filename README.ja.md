ページ本文はふつうの GitHub Markdown のままにして、レイアウト、include、CSS で整える Jekyll テーマです。

## 特長

- **ページには標準の Markdown だけ。** GFM と GitHub のアラートだけを使うので、同じファイルが github.com でもそのまま読めます。
- **GitHub Pages で動く。** レイアウトと include は Liquid だけなので、従来のビルドの `remote_theme` でも、Jekyll 4 でも動きます。
- **マークアップなしのコンポーネント。** アラート、ステータスバッジ、カード、タブ、ボタン、アコーディオン、ステップ、タイムラインなどが、ふつうの Markdown のパターンから作られます。
- **ページの種類。** ドキュメント以外にも多くのレイアウトがあります（[一覧](https://modootoday.github.io/jekyll-theme-modootoday/ja/reference/api/)）。ホーム、ブログとニュース、ディレクトリ（チーム、求人、イベント、スポンサー、ポートフォリオ）、詳細ページ、マーケティング（料金、機能、お問い合わせ、リンク集）、文書（規約、履歴書）、ドキュメント拡張（リファレンス、変更履歴、ロードマップ、用語集、講座、書籍）です。
- **デザインされたようなセクション。** `sections:` の項目には、`visual:` の include やコードと組み合わせる `c: split`、全幅の `bleed:` の帯、`reveal:` のフェードイン、4 列のカードなどを指定でき、分割ヒーローも同じように書けます。
- **23 言語、LTR と RTL。** テーマの文言は 23 言語にローカライズされ、言語メニュー、`hreflang`、右から左に書くレイアウトに対応します。
- **エージェントが読みやすい。** ページごとにバイト単位で同じ Markdown 版と、`llms.txt`、`llms-full.txt` を置けます。
- **アクセシブル。** キーボードショートカット、見えるフォーカス、スマートフォンのセーフエリア、44 px のタッチターゲット、ハイコントラストと視差効果を減らす設定が組み込まれています。
- **チェッカー。** `modootoday-check` がソースとビルド結果を検査します。
- **任意の機能。** 検索、ライト/ダークの切り替え、Mermaid の図と KaTeX の数式（既定ではオフで、使うページだけで読み込みます）、コミットした SVG ファイルと MathML で表示する静的な図と数式、schema.org JSON-LD があります。

## インストール

gem として（`theme:`）:

```ruby
# Gemfile
gem "jekyll-theme-modootoday", "~> 1.6"
```

```yaml
# _config.yml
theme: jekyll-theme-modootoday
```

Gemfile なしの GitHub Pages で（`remote_theme:`）:

```yaml
# _config.yml
remote_theme: modootoday/jekyll-theme-modootoday@v1.6.0
plugins: [jekyll-remote-theme]
```

タグかコミットで固定してください。最小の設定、チェッカー、スターターサイトは[インストールガイド](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/install/)にあります。

## クイックスタート

```sh
mkdir my-docs && cd my-docs
printf 'source "https://rubygems.org"\ngem "jekyll", "~> 4.4"\ngem "jekyll-theme-modootoday", "~> 1.6"\n' > Gemfile
printf 'theme: jekyll-theme-modootoday\nmarkdown: kramdown\nkramdown: {input: GFM}\nsass: {style: compressed, silence_deprecations: [import, global-builtin]}\n' > _config.yml
printf -- '---\nlayout: doc\ntitle: Home\n---\n# Hello\n\n> [!TIP]\n> Plain Markdown, styled.\n' > index.md
bundle install && bundle exec jekyll build
bundle exec modootoday-check . _site
```

手順を追うなら: [最初のページを書く](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/first-page/)。

## 考え方

- **本文はシンプルに、レイアウトは豊かに。** 本文は GFM で、front matter の `sections:` が `##` ごとにコンポーネントを対応させます。[コンポーネント](https://modootoday.github.io/jekyll-theme-modootoday/ja/components/)と[キッチンシンク](https://modootoday.github.io/jekyll-theme-modootoday/ja/components/kitchen-sink/)をご覧ください。
- **ルール。** 本文に書けるものと、各パターンが何に変換されるかは [RULES.md](RULES.md)（`md-components v1`）が決めます。
- **まずはふつうの Jekyll。** `jekyll new` で作ったサイトは、`_config.yml` のテーマの行と `Gemfile` のテーマの gem（`gem "minima"` の代わり）を変えるだけでビルドできます。`layout: page`、ホームの投稿一覧、ヘッダーの `header_pages` やタイトル付きのページ、あらゆる形の `author:` を読み込みます。[移行とアップグレード](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/upgrade/)をご覧ください。
- **設定とトークン。** `_config.yml` の `modootoday:` ブロック 1 つ、サイトが 1 つの Sass フック（`_sass/modootoday/_site.scss`、インラインスタイルなし）から設定する CSS カスタムプロパティ `--mt-*`、コンポーネントごとの Sass パーシャル。[設定](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/configuration/)と[カスタマイズ](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/customize/)をご覧ください。
- **ブログとニュース。** `blog`、`news`、`news-article`、`author`、`feed` のレイアウト: ページ送り付きのカード一覧（list、grid、magazine）、`_data/authors.yml` からの著者表示、シリーズ、関連する投稿、共有、JSON-LD、言語ごとの Atom フィード。Liquid だけで、スタイルとスクリプトは任意のバンドルです。[ブログとニュース](https://modootoday.github.io/jekyll-theme-modootoday/ja/layouts/blog-news/)をご覧ください。
- **データから作るページ。** `modootoday.records` は、`_data` ファイルのレコードごとに従来の Pages でページを 1 つずつ作ります。`modootoday-stubs --records` がレコードごとに front matter だけのページを書き、`records:` を付けたディレクトリのページがその一覧を表示し、`modootoday-check --byte-exact=api` はフォルダーがバイト単位のまま公開されたことを確かめます。[生成ページ](https://modootoday.github.io/jekyll-theme-modootoday/ja/recipes/generated-pages/)をご覧ください。
- **Markdown 版。** ページごとに、エージェント向けの Markdown 版を 3 つの方法のどれかで公開できます。下の [AI エージェント](#ai-エージェント)をご覧ください。

## AI エージェント

- `guide.md` の Markdown 版は `/guide/index.md` にあり、本文とバイト単位で同じで、`rel="alternate" type="text/markdown"` でリンクされます。
- `llms.txt` と `llms-full.txt` は `/` と各 `/<lang>/` の下にあります。
- Jekyll 4 では `plugins: [jekyll-theme-modootoday]` が作ります。従来の GitHub Pages のビルドは 1 ファイルのスタブを使い、スタブは `modootoday-stubs SRC --twins --write` が書きます。
- 任意の URL エイリアス（`modootoday.aliases`）: `/guide.md`（Markdown 版そのもの）と `/guide.html`（`/guide/` へのリダイレクト）は `modootoday-stubs SRC --aliases --write` が作ります。
- ソースモード（front matter のないページ、スタブなし）を含む詳細: [AI エージェントのガイド](https://modootoday.github.io/jekyll-theme-modootoday/ja/guides/agents/)、契約は [RULES.md §5a](RULES.md#5a-markdown-twins)、このリポジトリの [llms.txt](https://modootoday.github.io/jekyll-theme-modootoday/llms.txt)。

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 問題なし（`modootoday-stubs`: することなし、プレビューまたは書き込み完了） |
| 1 | 問題あり（stderr に出力）または使い方の誤り（`modootoday-stubs`: `--check` が差分を検出） |
| 2 | `modootoday-stubs`: 使い方の誤りまたは `_config.yml` のエラー |
| 3 | `modootoday-stubs`: データのエラー（front matter、安全でない permalink、エイリアスの衝突、キーがないか重複するレコード） |
