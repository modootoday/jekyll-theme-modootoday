# jekyll-theme-modootoday

페이지 본문은 평범한 GitHub Markdown으로 두고, 레이아웃·인클루드·CSS로 꾸미는 Jekyll 테마입니다.

## 왜

- **페이지에는 표준 Markdown만.** GFM과 GitHub 알림만 쓰므로 같은 파일이 github.com에서도 잘 읽힙니다.
- **GitHub Pages에서 동작.** 레이아웃과 인클루드가 Liquid만 쓰므로 기본 빌드의 `remote_theme`도 되고, Jekyll 4도 됩니다.
- **마크업 없는 컴포넌트.** 알림, 상태 배지, 카드, 탭, 버튼, 아코디언, 단계, 타임라인 등이 평범한 Markdown 패턴에서 나옵니다.
- **에이전트가 읽기 쉬움.** 페이지마다 바이트 단위로 같은 Markdown 쌍둥이와 `llms.txt`, `llms-full.txt`를 둘 수 있습니다.
- **검사기.** `modootoday-check`가 원문과 빌드 결과를 검사합니다.

## 설치

gem 방식(`theme:`):

```ruby
# Gemfile
gem "jekyll-theme-modootoday", "~> 0.5"
```

```yaml
# _config.yml
theme: jekyll-theme-modootoday
```

Gemfile 없이 GitHub Pages에서(`remote_theme:`):

```yaml
# _config.yml
remote_theme: modootoday/jekyll-theme-modootoday@v0.5.0
plugins:
  - jekyll-remote-theme
```

태그나 커밋으로 고정하세요. 자세한 내용: [설치 가이드](https://modootoday.github.io/jekyll-theme-modootoday/ko/install/).

## 빠른 시작

```sh
mkdir my-docs && cd my-docs
printf 'source "https://rubygems.org"\ngem "jekyll", "~> 4.4"\ngem "jekyll-theme-modootoday", "~> 0.5"\n' > Gemfile
printf 'theme: jekyll-theme-modootoday\nmarkdown: kramdown\nkramdown: {input: GFM}\nsass: {silence_deprecations: [import, global-builtin]}\n' > _config.yml
printf -- '---\nlayout: doc\ntitle: Home\n---\n# Hello\n\n> [!TIP]\n> Plain Markdown, styled.\n' > index.md
bundle install && bundle exec jekyll build
bundle exec modootoday-check . _site
```

따라 하기: [첫 페이지 쓰기](https://modootoday.github.io/jekyll-theme-modootoday/ko/first-page/).

## 개념

- **본문은 평범하게, 레이아웃은 풍부하게.** 본문은 GFM이고 `sections:` 머리말이 `##`마다 컴포넌트를 연결합니다. [컴포넌트](https://modootoday.github.io/jekyll-theme-modootoday/ko/components/)와 [키친싱크](https://modootoday.github.io/jekyll-theme-modootoday/ko/components/kitchen-sink/)를 보세요.
- **규칙.** 본문에 쓸 수 있는 것과 각 패턴의 변환 결과는 [RULES.md](RULES.md)(`md-components v1`)가 정합니다.
- **설정과 토큰.** `_config.yml`의 `modootoday:` 블록 하나, CSS 사용자 속성 `--mt-*`, 컴포넌트별 Sass 파셜. [설정](https://modootoday.github.io/jekyll-theme-modootoday/ko/configuration/)과 [커스터마이즈](https://modootoday.github.io/jekyll-theme-modootoday/ko/customize/)를 보세요.
- **쌍둥이: 세 가지 방식** — 스텁 파일(기본, 기본 Pages), `jekyll-theme-modootoday` 플러그인(Jekyll 4 / Actions), 또는 머리말 없는 페이지와 `modootoday.twins: source`(기본 Pages, 스텁 없음). [RULES.md §5a](RULES.md#5a-markdown-twins)를 보세요.

## 명령

`modootoday-check SRC SITE [옵션]` (`jekyll build` 다음에 실행, 표는 영어 원본에서 생성):

| Option | Checks |
|---|---|
| `SRC SITE` | always: front matter, forbidden syntax, alerts, fence info strings, `status:`/`tag:`/`since:`/`kbd:` values, `sections:` count, `_data/components.yml` (keys, slot contract counts per section, `parts` against `api.md` and the built HTML), Sass/CSS rules, unconverted markers in the build |
| `--twins` | every page has a byte-identical Markdown twin, per-language `llms.txt` and `llms-full.txt` |

| `--strict` | warnings fail the run |
| `--gh` | also render each page with `gh api markdown` (network, `gh` login) |
| `--help, -h` | print usage and options (`--help=markdown` prints the README table) |
| `--version` | print the rules version |

## AI 에이전트

- `guide.md`의 쌍둥이는 `/guide/index.md`이며 본문과 바이트 단위로 같고, `rel="alternate" type="text/markdown"`으로 연결됩니다.
- `llms.txt`와 `llms-full.txt`는 `/`와 각 `/<lang>/` 아래에 있습니다.
- Jekyll 4에서는 `plugins: [jekyll-theme-modootoday]`가 만들고, 기본 GitHub Pages 빌드는 파일 하나짜리 스텁을 씁니다.
- 자세히: [에이전트 가이드](https://modootoday.github.io/jekyll-theme-modootoday/ko/agents/), 이 저장소의 [llms.txt](https://modootoday.github.io/jekyll-theme-modootoday/llms.txt).
